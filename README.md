# WEATHER-APP
Weather App (OpenWeatherMap API) Descly forecast, and 5-day forecast of any city using the OpenWeatherMap API.  Features  City search  Temperature, humidity, weather icon  Hourly &amp; 5-day forecast  Day/Night background  Dark/Light mode  Tech Used  HTML, CSS, JavaScript, OpenWeatherMap API  Usage  Add your API key, open index.html, search a city.
